# Support

Before opening an issue:

1. Read the [README](README.md) and [integration guide](docs/INTEGRATION.md).
2. Check the [repository setup steps](docs/REPOSITORY_SETUP.md).
3. Search existing issues for the same behavior.
4. Use the issue form that best matches the problem.

Use bug reports for reproducible problems in the repository tools or website. Use pull requests for proposed research data and code changes.

Do not post API tokens, passwords, private database files, personal information, or unredacted diagnostic logs. For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This repository currently hosts the public network scaffold and progress site; it is not a download page for the full desktop application.
