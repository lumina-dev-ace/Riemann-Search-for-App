HOW TO READ THE NUMBER

Progress is not a guess.

The checkpoint represents the highest index for which every preceding index is present, unique, and marked as verified by the FLINT/Arb interval workflow. Candidates, partial ranges, and attempted computations do not advance it.

Scientific limitation

Automated data validation checks structure and declared provenance. It does not independently recompute the zeta function, and finite numerical verification is not a proof of the Riemann Hypothesis.
