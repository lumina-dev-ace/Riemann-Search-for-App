# Accepted range records

The manifest references each accepted, immutable JSON range by repository-relative path and SHA-256. Each range contains exact decimal-string indices and only stored numerical results; its end index is derived from the final result, never from a user-entered claim.

The initial repository intentionally has no range records. Do not add example or fabricated zeros. See `../schema/research_range.schema.json` and `../../docs/DATA_SCHEMA.md`.
